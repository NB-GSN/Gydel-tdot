# Tag der offenen Tür – Gymnasium Delbrück

## Geschichte Oberstufe: „Echt jetzt? Der Geschichts-Check“

Handy-Quiz mit 8 Quellen zur Quellenkritik (je 3 Antworten), für Zehntklässler vor der Oberstufenwahl.
Adresse: https://nb-gsn.github.io/Gydel-tdot/echt-jetzt/

Bild: Anton von Werner, „Die Proklamierung des Deutschen Kaiserreiches“, Fassung 1885, gemeinfrei (Wikimedia Commons).

## Philosophie Oberstufe: „Denk mal weiter! Der Philosophie-Check“

Handy-Quiz mit 6 Gedankenexperimenten zu den Themen des neuen KLP Philosophie Sek. II: eigene Meinung wählen (nichts wird gespeichert oder verschickt), danach ein Argument-Check mit Erklärung.
Adresse: https://nb-gsn.github.io/Gydel-tdot/denk-weiter/
